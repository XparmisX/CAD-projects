# صورت پروژه : طراحی شتاب دهنده شبکه عصبی
## هدف کلی پروژه به زبان ساده :
می‌خواهیم یک **تراشه‌ی کوچک (به صورت کد RTL)** بسازیم که یک عکس دست‌نویس از یک رقم (۰ تا ۹) را بگیرد و بگوید آن رقم چیست.
تشخیص را یک **شبکه عصبی** انجام می‌دهد. ما فقط **سخت‌افزارِ اجرای** شبکه را می‌سازیم (یادگیری از قبل انجام شده و وزن‌ها آماده‌اند).
 

هر نورون فقط یک کار می‌کند:
 
```
Hj = Σ_i ( Wij * xi ) + Cj
```
 
برای نورون `j`:
 
```
Hj = W0j*x0 + W1j*x1 + ... + W(n-1)j*x(n-1) + Cj
```
 
- `xi` ورودی شماره‌ی `i` است (در لایه‌ی اول: پیکسل‌های عکس)
- `Wij` وزن بین ورودی `i` و نورون `j` است؛ هر ورودی وزن مخصوص خودش را دارد
- `Cj` بایاس نورون `j` است؛ یک عدد ثابت برای همان نورون
- `Hj` خروجی نورون `j` است

پس سخت‌افزار ما اساساً یک **ضرب‌کننده + جمع‌کننده** است که این کار را چندین بار تکرار می‌کند:
لایه‌ی اول ۷۸۴ ضرب برای هر یک از ۸ نورون، و لایه‌ی دوم ۸ ضرب برای هر یک از ۱۰ نورون.
