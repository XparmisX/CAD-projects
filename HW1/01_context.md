# صورت پروژه : طراحی شتاب دهنده شبکه عصبی
## هدف کلی پروژه به زبان ساده :
می‌خواهیم یک **تراشه‌ی کوچک (به صورت کد RTL)** بسازیم که یک عکس دست‌نویس از یک رقم (۰ تا ۹) را بگیرد و بگوید آن رقم چیست.
تشخیص را یک **شبکه عصبی** انجام می‌دهد. ما فقط **سخت‌افزارِ اجرای** شبکه را می‌سازیم (یادگیری از قبل انجام شده و وزن‌ها آماده‌اند).
 

هر نورون فقط یک کار می‌کند:
 
```
Hj = Σ_i ( Wij * xi ) + Cj
```
 
برای نورون `j`:
 
```
Hj = W0j*x0 + W1j*x1 + ... + W(n-1)j*x(n-1) + Cj
```
 
- `xi` ورودی شماره‌ی `i` است (در لایه‌ی اول: پیکسل‌های عکس)
- `Wij` وزن بین ورودی `i` و نورون `j` است هر ورودی وزن مخصوص خودش را دارد
- `Cj` بایاس نورون `j` است یک عدد ثابت برای همان نورون
- `Hj` خروجی نورون `j` است

پس سخت‌افزار ما اساساً یک **ضرب‌کننده + جمع‌کننده** است که این کار را چندین بار تکرار می‌کند:
لایه‌ی اول ۷۸۴ ضرب برای هر یک از ۸ نورون، و لایه‌ی دوم ۸ ضرب برای هر یک از ۱۰ نورون.

## ابزارها و توضیحات کلی مربوط به کدنویسی


| ردیف | توضیحات |
|---|---|
| زبان | **SystemVerilog، نسخه‌ی IEEE 1800-2012** |
| شبیه‌ساز | **ModelSim** (کامپایل و اجرا) |
| بخش ترتیبی (رجیستر) | `always_ff @(posedge clk)` و فقط **nonblocking** (`<=`) |
| بخش ترکیبی | `always_comb` و فقط **blocking** (`=`)؛ همه‌ی خروجی‌ها در همه‌ی مسیرها مقدار بگیرند (بدون latch) |
| FSM | با `typedef enum`، یک بلوک برای ثبات state و یک `always_comb` برای state بعدی و خروجی‌ها |
| کلاک | یک کلاک `clk`، همه‌چیز روی **لبه‌ی بالارونده** یا **posedge** |
| ریست | یک `rst`، **سنکرون و active-high**. با `rst=1`: FSM به `done=0` برود |
| ممیز شناور | ضرب و جمع FP16 باید **در سطح بیت** در RTL نوشته می شوند |

## ساختار شبکه
 
مسیر داده: **۲۸×۲۸ = ۷۸۴ ← ۸ ← ۱۰**
 
1. **ورودی:** عکس سیاه‌وسفید ۲۸×۲۸ از MNIST، تخت‌شده به بردار ۷۸۴ تایی `x[0..783]` از اعداد FP16 (سطر به سطر).
2. **لایه‌ی ۱:** ۸ نورون، هر کدام به هر ۷۸۴ ورودی وصل است.
3. **ReLU** روی ۸ خروجی لایه‌ی ۱: اگر منفی بود صفر، وگرنه همان مقدار.
4. **لایه‌ی ۲:** ۱۰ نورون، هر کدام به هر ۸ خروجی لایه‌ی ۱ وصل است. بعد از لایه‌ی ۲ تابع فعال‌سازی نداریم.
5. **خروجی:** رقم پیش‌بینی‌شده = اندیس نورونی که `H` بزرگ‌تری دارد (۰ تا ۹). اگر مساوی شدند، اندیس کوچک‌تر.
تعداد کل ضرب‌ها برای یک عکس: `784×8 + 8×10 = 6352`

## عدد ممیز شناور ۱۶ بیتی (FP16)
 
قالب: `[15]` علامت، `[14:10]` توان (bias=15)، `[9:0]` کسر.
همه‌ی ورودی‌ها، وزن‌ها، بایاس‌ها و محاسبات FP16 هستند.
 
| ردیف | توضیحات |
|---|---|
| گرد کردن | **truncate** (بیت‌های اضافه بریده می‌شوند) |
| بیت محافظ در جمع | ندارد |
| Subnormal | به صفر تبدیل می‌شود (هم ورودی و هم نتیجه) |
| سرریز | به بزرگ‌ترین عدد متناهی `±0x7BFF` اشباع می‌شود |
| NaN | هر عملیات با NaN یا `Inf×0` یا `Inf−Inf` خروجی `0x7E00` می‌دهد (در داده‌ها NaN و Inf نداریم) |
| FMA | ندارد: ضرب جدا گرد می‌شود، جمع جدا. انباشتگر هم FP16 است |

## معماری سخت‌افزار

**مسیر داده:** حافظه ← ضرب‌کننده ← بافر پینگ‌پونگ ← جمع‌کننده

- **SRAM:** حافظه‌ی وزن‌هاست. با دریافت آدرس، پس از **۷ سیکل** یک سطر **۱۱۲ بیتی شامل ۷ عدد FP16** می‌دهد. این اعداد در ۷ رجیستر ذخیره می‌شوند تا پیوسته قابل استفاده باشند. چیدمان حافظه را خودمان تعیین می‌کنیم.

- **ضرب‌کننده FP16:** در هر سیکل یک ضرب وزن در ورودی انجام می‌دهد؛ پس ضرب‌های هر سطر در **۷ سیکل** تمام می‌شوند.

- **بافر پینگ‌پونگ:** دو بلوک A و B دارد که هرکدام ۷ عدد FP16 نگه می‌دارند. یکی داده را از ضرب‌کننده می‌گیرد و دیگری به جمع‌کننده می‌دهد؛ سپس جایشان عوض می‌شود. پرچم‌های `full/empty` یا `ready/valid` از بازنویسی داده‌ی خوانده‌نشده و خواندن داده‌ی نامعتبر جلوگیری می‌کنند. سطرهای زوج در A و سطرهای فرد در B قرار می‌گیرند.

- **جمع‌کننده:** حاصل‌ضرب‌ها را از بافر می‌گیرد و در یک رجیستر انباشتگر جمع می‌کند. با رسیدن آخرین ورودی نورون `Hj`، خروجی آماده می‌شود. سیگنال‌های `input_last` و `out_valid` به‌ترتیب آخرین ورودی و آماده بودن خروجی را مشخص می‌کنند.

- **لایه‌ی دوم:** هر نورون **۸ ورودی** دارد؛ بنابراین به ۲ سطر نیاز دارد: ۷ ضرب در سطر اول و ۱ ضرب در سطر دوم. خروجی‌های ReLU لایه‌ی اول در یک **رجیستر فایل ۱۰ تایی** ذخیره می‌شوند که ۲ رجیستر آن استفاده نمی‌شود. نتیجه‌ی هر نورون لایه‌ی دوم در رجیسترهای خروجی جداگانه ذخیره می‌شود تا ورودی‌ها تغییر نکنند. پس از آماده شدن هر ۱۰ خروجی، همه به‌صورت **موازی** روی خروجی قرار می‌گیرند و سیگنال `done` فعال می‌شود.

## ترتیب جمع

```
acc = Cj                   (بایاس، مقدار اولیه‌ی انباشتگر)
acc = acc + p[0]
acc = acc + p[1]
...                        (به ترتیب اندیس ورودی)
acc = acc + p[N-1]
Hj  = acc
```
